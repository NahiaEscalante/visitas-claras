## ⚠️ Notas Importantes

- **Todas las contraseñas son simples** para facilitar las demostraciones
- **Los datos persisten** en localStorage entre recargas
- **Los archivos subidos** solo existen durante la sesión actual
- **El sistema simula delays** realistas (2-4 segundos para IA)
- **Los errores son simulados** ocasionalmente (5% de probabilidad)

## 🔄 Resetear Datos

Si necesitas resetear todos los datos a su estado inicial:

```javascript
// En la consola del navegador
localStorage.clear();
location.reload();
```

Esto eliminará:
- Todas las visitas creadas
- Todas las visitas programadas
- La sesión actual
- Cualquier dato personalizado
